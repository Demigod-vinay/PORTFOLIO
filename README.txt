VINAY KUMAR — PORTFOLIO
========================

Files:
- index.html : page structure and resume content
- style.css  : responsive dark-blue visual design
- script.js  : mobile navigation, current year, scroll reveal
- assets/resume.pdf : résumé link (add your PDF here)

Run locally:
1. Keep index.html, style.css, script.js and assets folder together.
2. Open index.html in a modern browser.
3. For editing, use Visual Studio Code. You can install the Live Server extension and choose "Open with Live Server".

Before publishing:
- Check that contact details and descriptions are accurate.
- Add GitHub project links/live demos where available.
- Replace assets/resume.pdf with your latest résumé PDF.
- Do not publish private information you do not want public.

This is a static HTML/CSS/JavaScript portfolio and does not require Python, Java, or a backend.
